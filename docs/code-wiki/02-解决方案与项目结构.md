# 02 · 解决方案与项目结构

## 1. 解决方案

- 文件：`PCL Community Edition.slnx`（.NET 新式 XML 解决方案格式）
- 构建配置：`Debug`、`CI`、`Release`、`Beta`
- 目标平台：`AnyCPU`、`x64`、`ARM64`
- 版本号：`2.15.1`（定义在 `PCL.Launcher.csproj`）

```xml
<Solution>
    <Configurations>
        <BuildType Name="CI" />
        <BuildType Name="Beta" />
        <BuildType Name="Debug" />
        <BuildType Name="Release" />
        <Platform Name="AnyCPU" />
        <Platform Name="ARM64" />
        <Platform Name="x64" />
    </Configurations>
    <!-- 8 个项目 -->
</Solution>
```

各项目统一使用：

- `TargetFramework = net10.0`（源生成器为 `netstandard2.0`）
- `LangVersion = 15.0`
- `Nullable = enable`、`ImplicitUsings = enable`
- 根命名空间统一为 `PCL` 系列（`PCL.Core`、`PCL.Launcher` 等）

## 2. 项目职责

### 2.1 `PCL.Core`（核心基础设施）

- 输出：类库
- 依赖：CommunityToolkit.Mvvm、Wacton.Unicolour、System.Management、ProtectedData/CNG、SharpZipLib、Microsoft.Data.Sqlite、SQLitePCLRaw、YamlDotNet、fNbt、LiteDB、Ae.Dns.Client、Microsoft.Extensions.Http、Polly、Humanizer、Microsoft.Extensions.Logging、Sentry、System.IdentityModel.Tokens.Jwt、FluentValidation
- 引用源生成器：`OutputItemType="Analyzer" ReferenceOutputAssembly="false"`
- 主要目录：

| 目录 | 职责 |
|---|---|
| `App/` | 配置、生命周期、DI、事件总线、日志门面、数据库、CLI、本地化、Essentials 服务 |
| `IO/` | 文件/目录、INI、字节流、管道、HTTP、DNS、Socket、缓存、哈希存储 |
| `Minecraft/` | Java、账户、启动参数、存档、资源项目、Maven、NBT、版本信息 |
| `Link/` | 联机大厅、Natayark、EasyTier、MC Ping、Scaffolding 协议 |
| `Platform/` | 平台与 UI 抽象接口、`ApplicationRuntime`、能力描述 |
| `UI/` | 核心层 UI 抽象（对话框、提示、主题、调度器） |
| `ViewModel/` | MVVM 基类、异步状态、本地化属性 |
| `Utils/` | 哈希、加密、校验、编码、操作系统、差异比较、SemVer |
| `Diagnostics/` | 性能与诊断辅助 |
| `Windows/` | Windows 专用互操作与 WinRT 封装（条件编译） |

### 2.2 `PCL.Core.SourceGenerators`（源生成器）

- 输出：`netstandard2.0` 分析器
- 依赖：`Microsoft.CodeAnalysis.CSharp 5.12.0`、`Microsoft.CodeAnalysis.Analyzers`
- 文件：6 个增量生成器 + 共享工具（详见 [10-源码生成器.md](10-源码生成器.md)）

### 2.3 `PCL.Core.UI`（Avalonia UI 适配层）

- 输出：类库
- 依赖：Avalonia 12.1.6、Microsoft.Extensions.DependencyInjection 11、PlainToolkit.ObjectiveC
- 通过 `<AvaloniaResource Include="..\PCL.Localization\Languages\*.axaml">` 把语言文件链接进程序集
- 主要目录：`Animation/`、`Clipboard/`、`Dialogs/`、`Hosting/`、`Localization/`、`Notifications/`、`Resources/`、`Theming/`、`Threading/`
- 关键入口：`AvaloniaUiServiceRegistration`、`UiModuleFactory`

### 2.4 `PCL.Launcher.Core`（业务核心）

- 输出：类库
- 依赖：Dapper 2.1.89、protobuf-net 3.4.40、`PCL.Core`
- 许可证：`PCL.Launcher.Core/LICENCE`（与主仓库 Apache-2.0 不同）
- 主要目录：

| 目录 | 职责 |
|---|---|
| `Comp/`、`CompDependency/`、`LocalComp/` | 社区资源（整合包/模组/资源包等）模型、查询、下载、依赖解析 |
| `Download/` | 各加载器与游戏文件下载、安装请求 |
| `Install/` | 安装管线、恢复、实例 JSON 合并 |
| `Launch/` | 启动前检查、参数、Java、登录、Natives、进程运行 |
| `Loading/` | 加载任务框架（任务、组合任务、进度、显示） |
| `Minecraft/` | `McInstance`、版本信息、版本比较/约束 |
| `Modpack/` | CurseForge/Modrinth/MultiMC/HMCL/MCBBS/LauncherPack 整合包解析 |
| `Network/` | 业务网络辅助 |
| `Updates/` | 启动器自更新 |
| `Watcher/` | 文件/目录监视 |
| `CrashAnalysis/` | 崩溃日志分析 |
| `Ui/` | 业务层 UI 契约（由界面层实现） |
| 根目录 | `LauncherPaths`、`LauncherState`、`FileChecker`、`SafeList`、`Search` |

### 2.5 `PCL.Platform`（平台原生实现）

- 依赖：Microsoft.Extensions.DependencyInjection、PlainToolkit.ObjectiveC、`PCL.Core`
- 目录：`Windows/`、`Linux/`、`MacOS/`、`Posix/`、`Shared/`
- 关键入口：`PlatformModuleFactory`、`PlatformServiceRegistration`
- 职责：把 `PCL.Core.Platform` 接口映射为各操作系统实现（路径、代理、快捷方式、回收站、GPU 偏好、启动脚本等）

### 2.6 `PCL.Launcher`（界面层 / 组合根）

- 输出：`WinExe`
- 依赖：Avalonia 全家族、`JAJ.Packages.MiniAudioEx`、Microsoft.Extensions.DependencyInjection、PlainToolkit.ObjectiveC、`PCL.Core.UI`、`PCL.Launcher.Core`、`PCL.Platform`
- 关键属性：
  - `AvaloniaUseCompiledBindingsByDefault = true`（编译绑定）
  - `ApplicationIcon = Assets/Images/icon.ico`
  - `ApplicationManifest = app.manifest`
  - 非 Debug 配置下排除 Avalonia 诊断包、发布后删除 `.pdb`
- 内嵌资源：`Resources/metadata.json`、`Resources/*`、`Resources/hints/*.txt`
- 主要目录：

| 目录 | 职责 |
|---|---|
| `Composition/` | DI 注册、启动命令处理 |
| `Navigation/` | 页面描述、目录、路由、宿主、状态机 |
| `Views/` | `MainWindow`、Shell、Pages、对话框 |
| `ViewModels/` | 页面、实例、启动、下载、设置等 ViewModel |
| `UI/` | 桥接、对话框/提示呈现、控件、主题、样式、系统集成、诊断 |
| `Media/` | 背景音乐播放（MiniAudio） |
| `Platform*/` | 平台启动适配（Windows/Linux/macOS） |
| `Assets/` | 图标、图片、字体、图标包 |

### 2.7 `PCL.Localization`（中立语言资源）

- 输出：类库
- 无第三方依赖
- `Languages/*.axaml`：`zh-CN`、`zh-TW`、`en-US`、`en-GB`、`es-ES`、`fr-FR`、`ja-JP`
- `LocalizationCatalog`：不依赖 UI 框架，读取内嵌语言资源，供测试/i18n 校验使用
- 注意：界面运行时实际使用的是 `PCL.Core.UI` 通过链接方式打包的同一份 `Languages/*.axaml`

### 2.8 `PCL.Core.Test`（测试）

- 输出：类库；`Microsoft.NET.Test.Sdk`、MSTest Adapter/Framework、fNbt、SQLitePCLRaw
- 引用除源生成器外的全部项目
- 组织方式见 [11-测试体系.md](11-测试体系.md)

## 5. 构建配置差异

| 配置 | 常量/行为 | 用途 |
|---|---|---|
| `Debug` | `DEBUG;TRACE`，保留 Avalonia 诊断包与 PDB | 本地开发 |
| `CI` | `TRACE`，关闭调试专用路径 | 持续集成构建与测试 |
| `Release` | `RELEASE;TRACE`，发布时删除 PDB、排除诊断包 | 正式发布 |
| `Beta` | `BETA;PUBLISH;TRACE`，发布构建 | Beta 渠道 |

`Basics`、`Paths`、`Config` 等会根据这些常量切换行为（例如测试配置目录、调试日志、发布形态路径）。
